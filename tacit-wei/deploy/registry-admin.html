tacit pay registry

The lists and switches the tacit pay page reads from TacitPayRegistry on Ethereum.

Flags

A set bit turns the feature off. The page reads them once per session.

new value

Recommended entries

What the tacit.wei page expects the registry to hold. Only missing entries are added, one transaction each from the owner wallet; nothing is removed or reordered.

    Another list

    Ownership

    Two steps: the owner offers, the new owner accepts. Offering 0x000…000 withdraws an offer. There is no renounce.

    Last payload

    Built for every action, so an owner that is a contract can submit the same call. The registry's owner is the ops multisig (0x006CD14F36F65eCbB29b2519cCBe63A0DC8549F2, 2 of 5, one-hour delay): each payload goes through its queue (execute with two owners' signatures over the op id, then executeQueued after the delay), from the ops page (registry-admin's ops.html). Check the effect on chain afterwards: the multisig answers an unknown call with success.
